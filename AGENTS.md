# Solus standalone repository

Keep the integrated SPEDA module intact; this repository is a runnable portfolio edition. Never copy real databases, `.env`, private keys, owner memory or production records into it. Preserve the AGPL-3.0-or-later copyright/license notices.

Exact accounting belongs in services and the command coordinator. Routers only adapt requests. Money is plain decimal input converted to integer minor units; every currency balances independently. Posted history is immutable and corrections use reversals. Original source payloads and retry receipts commit atomically.

No default credentials, hardcoded personal card dates or AI-derived authoritative totals. An assistant may propose a command; a trusted owner review controls execution. No model or external provider call belongs inside a writer transaction.

Set `PYTHONDONTWRITEBYTECODE=1` for Python runs. Pytest cache is disabled. Test databases/screenshots/scratch directories belong in the OS temporary directory, outside the checkout. Do not commit generated UI bundles, dependency trees or build products. Build the UI before HTTP tests.
